# `vwc-notifications-menu-notification` / `NotificationsMenuNotification`

A single notification entry inside [`vwc-notifications-menu`](../notifications-menu/CONTEXT.md). Generally rendered automatically by the parent menu's default renderer; expose this directly only when a custom renderer is needed.

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `notification` | `VectorNotification \| undefined` | `undefined` | The notification data to render. |

See `VectorNotificationsMenuNotificationProps` export for the full prop type.
