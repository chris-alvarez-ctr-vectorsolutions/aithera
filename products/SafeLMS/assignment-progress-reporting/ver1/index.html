How progress is counted

Completed — a completion record exists.
In progress — opened course content, but hasn't completed. Accepting the course disclaimer on its own doesn't count. For a bundle, opening any course inside it counts.
Not started — assigned, but hasn't opened any course content yet.
Each assigned learner is in exactly one state, so the three always add up to the total assigned. Compliance is unchanged: completed ÷ assigned.
