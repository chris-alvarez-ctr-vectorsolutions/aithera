Driving the demo

  • Onboarding: the verification email “arrives” a beat after you reach the code screen — tap it and the code fills itself. Voice samples use the browser's built-in speech (a stand-in for produced voices). The dashboard's Settings gear has restart onboarding and replay CLARA's intro.
  • Skip this learning object (top right on gated steps) is an internal review affordance only — learners won't have it in product. Results stay honest about what was skipped.
  • Demo: flip entry result (top right on “Your Path, Compressed”) replays the entry compression as the opposite result — two beats compressed vs. the full build. The section counter genuinely changes.
  • Trigger remediation naturally: answer the mastery check's second item weakly and watch the path grow a step on the spot. Ace the entry battery's second question to earn the advanced-tier (test-up) locked item.
  • The Marshall scenario runs live AI; everything else is deterministic, so the demo can't drift.
