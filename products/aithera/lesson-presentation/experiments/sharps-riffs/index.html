Sharps Riffs

Standalone visual/interaction experiments riffing on moments from the Sharps module — not wired into the real module or the Demo menu, so nothing here can touch the shipped experience. Freely disposable. Riffs badged Live model call make a real request to the deployed Worker/Haiku 4.5; everything else is scripted — canned dialogue or keyword-checked, no model in the loop. Riff 07 is mostly scripted and badged for its one live step.

    00 — Contain the Sharp (full module)
    The complete Sharps module as it stood on 2026-09-22, frozen before the original was reworked — every beat, sector scenario and record screen, running on its own vendored copy of the engine so later changes can't reach it.
  • Scripted · no model
    01 — A Critical Choice
    The unclaimed-blade decision (D1), reframed as a first-person binocular scan into a coach panel styled after CLARA's own brand.
  • Scripted · no model
    02 — Path Update (gamified)
    "Your Updated Path" reimagined as a reward: confetti + a one-line "time saved" callout for a learner who tested out, no list of what changed.
  • Scripted · no model
    03 — Path Update (minimal)
    Same moment, opposite bet: a progress bar stands in for the adjustment and never says what moved. A toggle compares deterministic vs. non-deterministic bars AND the production screen's own itemized reveal, side by side.
  • Live model call
    04 — Choice Reflection
    Same chain (D1's Chris/Jacob setup), but CLARA asks why you didn't pick the other route before it plays out — then closes by weighing your own words against what you just watched happen.
  • Live model call
    05 — Teach Back
    Teach-back: explain the unclaimed-blade rule from Riff 01 to a new hire, talking or typing into one shared 30-second response — the AI Coach scores it against a 3-point rubric and reacts to what you actually said.
  • Live model call
    06 — Teach Back (Evidence)
    Same activity as Riff 05, one layer deeper: check your answer for a quick reinforcement summary, then — on a long-enough answer — the same field lights up with your own words color-coded to the rubric, tap a phrase to see why it counted.
  • Live model call · scene only
    07 — Battery into Path
    The pre-check and "Your Updated Path" as one page: submit the last question and that card drops off the stack, with the path summary resolving behind it. Continue goes straight to the first case, and the rest of the module plays on from a snapshot of 2026-09-23. Scripted throughout, except the scene step when set to simulator mode, which grades typed answers with a live model call (falling back to keyword checks offline).

“Do” activities

Seven low-cost ways for a learner to show they've taken in a module, priced between no model calls and the full scenario simulator. Sharps content is stand-in copy. Add ?offline=1 to any of them to force the scripted stand-in. Compare all seven by cost, effort and evidence.

  • Scripted · no model
    D1 — Fix the message
    Swap the problem phrases in a draft chat message to a coworker, then see how they reply.
  • Live model call · 1 call
    D2 — Write it up
    Write the incident report from what was reported. Conclusions stated as fact get flagged in your own words.
  • Live model call · 3 tiny calls
    D3 — Ask three
    Three questions to the coworker after a near-miss. The questions you choose are the evidence.
  • Live model call · 1 call
    D4 — Defend your call
    Pick what to fix first, then say why in one sentence. Separates a good guess from understanding.
  • Live model call · 1 call
    D5 — Spot the flaw
    Find the one wrong sentence in a plausible explanation, then say what it should say.
  • Live model call · 1 call
    D6 — Fresh case
    The model writes a different situation for each learner; rules do all the grading.
  • Live model call · 1 call
    D7 — Probe the miss
    A rules-only check, then one question aimed at your specific mistake.
