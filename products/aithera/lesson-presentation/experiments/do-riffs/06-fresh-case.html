Designer notes

    
    
      
  • Tests: whether a generated, per-learner case can still be graded by plain rules, so answers are individual without a model judging them.
    • 
      
  • Cost: 1 short Haiku call per case (output capped at 450 tokens, roughly 150-250 used). Grading: zero calls. Add ?offline=1 to force the pre-written pool.
    • 
      
  • Scripted: hazard bank, the three response options, the correct answer, the "why" lines, the workplace list, all grading, the pool of 4 fallback cases. Live: only the setting sentence, role wording and one scene sentence per hazard. Code rejects any case that changes ids or leaks advice.
    • 
      
  • Stand-in content written from general sharps-safety practice; it is not official course copy.
    • 
      
  • A real build still needs: reviewed hazard bank per module, a check that each generated scene truly matches its hazard (code only checks shape, not meaning), response options shuffled and tested for ambiguity, logging of seeds for audit, and a plan for when the live worker is unavailable.
