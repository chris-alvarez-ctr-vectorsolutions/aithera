Where should the "step out to coach" affordance live?

The label-mode prototype parks a passive mode badge + an escape button on a full-width secondary strip. In the scene that strip carries one pill and one button — it reads as an empty bar. Five directions for re-homing it, including the "peek the coach" idea.

The key realization: the only thing that truly needs a persistent home is the escape hatch. Which mode you're in is already obvious from context — the dark scene with a "What do you do or say?" composer vs. the coach sheet. So most options below can drop the standalone label entirely and only keep a way out. The return trip (coach → scene) already has its own CTA ("Back to practice"), so we're only placing one control.

1Fold it into the course header

Put the mode tag and a compact "Coach" button into the blue band you already have, beside Restart. The secondary strip is deleted; the scene rises to meet the header.

Zero new chrome — reuses a bar that's always there. Cleanest de-dupe.
The band is production frame chrome (frame.css); wiring player controls into it couples the two. Space is tight next to Restart on narrow screens.

2Peek the coach at the bottom (your idea)

The coach panel never fully leaves — a slim lip stays docked above the composer. Tap or swipe it up to step out; it collapses back when you return. Collapsed = practice, expanded = coaching, so the state is the label.

Co-locates "go to coach" with the coach itself; feels like a familiar chat drawer. No top chrome at all.
Two stacked elements compete for the bottom (peek + composer); a persistent lip eats a little scene height. Needs a real collapsed-coach state built.

5Lean on the scene card + a quiet corner link

Delete the badge outright — the scene card's eyebrow already names the mode ("Scene · you're in it"). Keep only a low-key "Step out to coach" link pinned to the stage's top corner.

The least chrome of any option; leans fully on context that already exists.
The escape is quiet — easy to miss for a learner who wants help. The eyebrow scrolls with content, so it isn't a fixed status line.
Label dropped — card eyebrow

My lean

Option 2 (peek the coach) is the most promising and it's your instinct — it kills the top strip, and it's honest about the interaction: the coach is a place you rise into and fall back from, so a docked lip you pull up matches the mental model better than an abstract control. The build cost (a real collapsed-coach state) is the only catch.

If we want something we can ship this week with near-zero risk, Option 3 (floating Coach button) or Option 4 (composer row) get 90% of the win by just relocating the button off the strip and dropping the label — both are small, local changes to the prototype.
