Implementation notes for the team · not part of the product UI

V1 · mapped to VPATH-15545

  1. Student profile, Courses tab (§1): read-only table with Course, Status (Complete, In Progress, Withdrawn), and the two new columns: Grade Level (the grade the course was taken) and Score (numeric or Pass/Fail as ingested). The Exams tab mirrors it for exam records.
  2. Manage > Student Courses (§2): Course is a hyperlink to the course detail page. Number of Students and Classification come from OneRoster section data; subject is conveyed by the course name and classification, so there is no separate subject column.
  3. Course detail (§3): course name at the top, roster table (Student Name, Status, Grade Level, Score) and the standard filters: Archived/Unarchived/All, Student Name, Status, Grade Level, Score. Filters and pagination are functional in this mock.
  4. Manage > Student Exams + exam detail (§4, §5): same pattern as courses. The label stays Exams to match Seals terminology, and exams are captured independently of courses (NY Regents style).
  5. Navigation (§6): breadcrumb in the top bar updates per page and is clickable; detail pages also carry "Back to Courses" / "Back to Exams" links, matching the existing pattern.

Scope guardrails

  • Read-only everywhere by design. No edit, add, or delete affordances; corrections ship with the separate correction epic.
  • Audience is school admin, district admin, org admin, and counselor. Teacher is excluded from the profile view. All four roles see the same surface, so there is no role switcher in the mock.
  • Deferred per the PRD: renaming "Unarchived" to "Active", Student Central tab cleanup, the static right-panel navigation issue, and the student-facing progress view.

Assumptions to confirm (platform screenshots welcome)

  • Profile header layout and the tab set (Student Central, Courses, Exams, Achievements, Documents) are approximated; only Courses and Exams are functional here.
  • "Manage" is mocked as a sidenav group holding Student Courses and Student Exams; confirm where these pages live in the real navigation.
  • Classification values shown (Honors, General Education, Advanced Placement) are examples; real values flow straight from the OneRoster feed.
  • The Score filter uses ranges (90 and above, 80 to 89, and so on) plus Pass, Fail, and No score; happy to align to the platform's existing score filter if one exists.
  • Students in the sidenav jumps straight to Emily Growler's profile in this demo; the students list itself is not part of this epic.
