Implementation notes for the team · not part of the product UI

V2 · platform-native restyle + 7/29 feedback round (VPATH-15545)

  1. Chrome: rebuilt from live-platform screenshots: VectorSolutions top bar with slash breadcrumbs and command-K search, gray sidenav (Manage active for these pages), Student Details card with Impersonate, and the existing tab row now carrying Courses and Exams. Test Scores stays as its own existing tab.
  2. Grids: filters moved into the column headers: the funnel opens the platform's standard filter popup (operator + value, live). Headers click-to-sort. "Showing X of Y" and "No Rows To Show" match the platform grid.
  3. Exams tables: new Category column (grouping such as Regents_Math), Upload Date column, Status column removed, and records that are In Progress or Withdrawn are filtered out everywhere exams render. Counts reflect completed records only.
  4. Courses tables: Upload Date added; Grade Level renders as a number in all grids.
  5. Names: all student names format as Last, First and link to that student's Student View. Any student opens a real profile: their course and exam records derive from the same section rosters.
  6. Sections: each course splits into sections that drive rosters. Expanding a course in Student Courses shows a sections table (Instructor, Section, Number of Students, View Section). View Section opens the course table with the Section column's header filter pre-applied; clearing that filter from the funnel shows the whole course. Rosters carry Section and Teacher columns.
  7. Banner: per-surface wording plus a computed Last upload date; the exams banner states that only completed exam records are shown.

Assumptions to confirm

  • Category values (Regents_Math, Regents_SS, Regents_ELA, Regents_Science, CTE_Assessment) follow the "Regions_Math" example; one array to change if the feed differs.
  • The Manage landing here is a demo hub only, so the flow is navigable; confirm where Student Courses / Student Exams live in the real Manage area.
  • Archived/Unarchived/All sits above the roster grids since archived state is not a column; the rename to "Active" stays deferred per the PRD.
  • Upload Date = the date the record's data was received (nightly upload batches in this demo: 07/22, 07/25, 07/28).
