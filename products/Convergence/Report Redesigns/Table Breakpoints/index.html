Implementation note: Use table-layout: auto (the default) with min-width on each column and overflow-x: auto on the wrapper. Do not set a fixed width: X% on columns — that forces compression regardless of content. With auto layout the browser sizes each column to its content (wider when there's room) and never shrinks below its min-width, triggering scroll instead.
