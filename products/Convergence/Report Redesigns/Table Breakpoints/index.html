Implementation note: All breakpoint widths and column widths are wired to CSS custom properties at the top of the stylesheet (--bp-*, --cw-*). Stage classes .stage-xl … .stage-xs on the <table> override only the long-text column widths (and switch wrap → truncate behavior) — short columns inherit stable defaults so numeric / status cells never dance around as the viewport flexes.

Resize behavior: Hover the right edge of any column header in the simulator to grab the resize handle. Once a column is dragged, it's pinned at that pixel width — viewport-stage changes leave it alone, and if the total of all column widths exceeds the simulated viewport the table-container scrolls horizontally instead of compressing the pinned column. The simulator toolbar shows how many columns are pinned and offers a "Reset" link to clear all pins.
