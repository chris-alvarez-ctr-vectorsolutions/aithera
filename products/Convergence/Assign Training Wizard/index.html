Scheduling

What kind of assignment is this?

A single assignment is due once. A recurring assignment comes back on a schedule, for example annual refresher training.

When should this assignment start?

Start date and start time are both required. Use Set to Now to make the training available immediately.

When is this assignment due?

Learners are marked overdue after the due date. Leave it open if the training has no deadline.

The first occurrence starts on this date (defaults to now). Each later occurrence starts after the recurrence interval.

When should the next occurrence become available?

Give learners a window to complete the training before it recurs so their status never lapses.

What if a learner has already completed this training?

Applies to learners who completed any of the selected training before this assignment was created.

How should future additions be handled?

People added later to the selected teams, departments, sites, divisions, organizations, or groups will receive this assignment automatically.
