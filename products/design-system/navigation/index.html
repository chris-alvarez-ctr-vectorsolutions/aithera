Vector navigation shell · 7 versions

One shell, real products: every version wraps the actual Vector suite (Convergence · Vector EHS Management · Vector Scheduling + a cross-product Dashboard). V1 is the reference; V2a/V2b explore Convergence Learner/Admin sub-products switched from the side nav (with two filter treatments on the real Training Plan); V3 moves the switcher to an app rail and search into the side nav; V4 to V6 vary only how the side nav shows hierarchy. The bottom-left pill switches versions and toggles the customer logo, location picker and tabs. Earlier explorations live in archive/.

Fixed in every version: the shared shell contract
Nav open/close App switcher Product · Location Scoped search Alerts Help Avatar
The nav open/close control is always the far-left item, directly above the side nav's edge; the app switcher sits next to it and owns that corner in every product. Switching ≠ navigating: other products never appear inside the current product's nav tree, and universal actions never move. Only the middle (mode tabs or nothing) and the side-nav pattern vary per version.
Menus borrow two things from Convergence + EHS (the visual style stays this exploration's own): the disclosure chevron trails the label and flips when open, as in .sn-row / .sb-item, so an expandable row and a plain row at the same level share one icon x and one label x; and the menu vocabulary echoes the real products' IA: Organization / Teams / Departments, Curricula, Qualifications, Activities, My recents / Scheduled reports on the Learn side; Incidents summary, Investigations, Corrective actions, OSHA logs, and the Safety Management long tail (Hazards, JSA, SDS, Tasks, Events, Document library, Observations) on the Comply side.

V1 · Grid launcher · global scoped search

Switcher: waffle launcher + Dashboard Search: top bar · All / product scope Tabs: in top bar

The reference shell: waffle launcher, location tree picker with a level subtitle, top-bar scoped search, in-bar mode tabs, 3-level accordion nav. Closing the nav now collapses it to a thin icon-only panel, and the profile menu sets side-nav text size (compact / default / comfortable). Review pill toggles logo, location and tabs.

V2a · Learner/Admin sub-products · filter panel

Sub-products: dropdown in the side nav Tabs: none Filters: right panel

Convergence splits into Learner and Admin experiences, switched from a dropdown at the top of the side nav. Learner holds Home + Training plan; Admin holds the full admin tree including Reporting. No top tabs, so the Convergence-style training plan carries its filters in a persistent right panel (status, type, due, with counts).

Where this lands

V1 vs V3 decides the switcher and search placement. V2a vs V2b decides how Convergence's Learner/Admin split behaves without top tabs, and which filter treatment the Training Plan gets (persistent right panel vs dropdown chips). V4 to V6 pick the side-nav depth language on an identical shell. Shell-wide behaviors are shared: collapse-to-icon-panel, profile-menu text sizing, location tree picker with level subtitles, and the scoped search naming its scope.
