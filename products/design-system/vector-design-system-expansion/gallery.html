Summary

Vector + Vaadin together cover ~85% of what the v4 prototype needs, not ~60% as the Vector-only reference doc suggested. Two passes mattered: Pass C revealed Vaadin primitives the team didn't know about; Pass D pulled live Storybook schemas and proved several documented features weren't in the reference doc. Notable corrections: vwc-drawer already supports position="bottom"; vaadin-button already ships theme="success primary" and theme="error primary"; vwc-sidenav already has the left-border active state via CSS tokens; vaadin-popover theme="no-padding" + <vwc-item itemRole="menuitem"> is the documented menu recipe. The remaining ~15% is mostly variant proliferation on existing primitives (status pill additions, count-badge slot on tabs, KPI composition on Card, chip styling), ~3 net-new primitives (empty-state, prefix-slot search field, dedicated chip), the entity-panel composite, and glass theme formalization. The biggest immediate productivity win is education + migration, not new components.
See gap-analysis.md for the full 30-row prioritized backlog, the Pass C + D reclassifications, the ~9 net-new Vector components that weren't in the reference doc, and the gap themes.
