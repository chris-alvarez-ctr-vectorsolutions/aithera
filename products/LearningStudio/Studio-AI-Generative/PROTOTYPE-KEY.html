Studio AI Generative — Prototype Key

Authors here don’t build content; they direct it. They write a brief, get a generated activity back, point at what’s wrong, and get the next generation. This key shows how the pieces connect and what each colour and marker in the prototype means.

Open the prototype Forklift-safety seed: six points, five activities, three outputs.

1The four layers

Each layer feeds the one below it. The check runs back up: every output is measured against the information set.

2The loop

Nothing is edited by hand. Notes fix this generation; editing the brief or spec changes what the activity is and starts a fresh one.

3What decides “good enough”

No activity carries its own bar. Depth is three levels: Awareness (knows it exists), Working (can do it with support), Mastery (can do it unaided). The prototype runs under a Compliance goal, so the SME must confirm every depth.

4How an output is built

The author writes a composition brief: a default path, rules in plain language, and a completion rule. The composer proposes the map. A Course is one straight path; an Experience routes each learner by what they just did.

Rule 3 lets a Strong learner skip the check. The composer inserts the inspection card on that path so P1 still reaches its bar. P3 can’t be repaired that way, because only the check teaches it to Mastery. So it’s flagged, and the author’s fix is to pin the check as required.

Terms

In the order you meet them, top layer to bottom.

Information set
The points a learner must know, each with a required depth. Decided by the SME.
Point
One teaching point, written as a document the AI generates from. Never shown to learners.
Depth
Awareness (knows it exists) · Working (can do it with support) · Mastery (can do it unaided).
Goal
The project’s evidence standard. Decides whether an SME must confirm depth. The prototype uses Compliance.
Project brief
How everything is delivered: style, voice, audience, standing constraints. Set once for the project.
Activity spec
One activity’s row in the brief: its points, modality and treatment. Inherits the brief, overrides what it needs.
Generation
One generated version of an activity, numbered 1, 2, 3. Never edited; replaced by the next.
Element
Any part of a generation you can point at: a narration line, a sign, a dialogue turn.
Annotation
A note pinned to an element, saying what’s wrong.
Revision task
All your notes from one review, sent together. Produces the next generation.
Drift
A change nobody asked for, caught by comparing generations.
Coverage claim
A generation’s statement that it teaches a point, at a depth, and where.
Beat
A step every learner must pass through. Claims on content generated live, like a scenario, are anchored to one.
Format
Full course, Refresher or Microlearning. Set on an output; sets the bar it’s checked against.
Composition brief
An output’s default path, routing rules and completion rule.
Rehearsal
Re-running something generated to judge its range: a scenario’s replies, or an output’s paths.
Learner preview
Walking it exactly as a learner would. Approvals are given from its report.
Pipeline handoff
The approval that sends a whole output to publishing. Cleared by any later change.
LED / SME
Learning experience designer (the author) / subject-matter expert.
