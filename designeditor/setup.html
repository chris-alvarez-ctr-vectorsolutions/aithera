Design Editor — Setup

A private, browser-based overlay for making manual Figma-lite tweaks to any prototype and exporting them to Claude. Nothing is added to your mock files and nothing ships to GitHub Pages.

1. Set your live-server port

Whatever port your local server serves the repo on (VS Code Live Server defaults to 5500). This rebuilds the bookmark below to point at it.

2. Drag this into your bookmarks bar

✏️ Edit Mode

Drag the button up to your browser's bookmarks bar. (If your bar is hidden: ⌘⇧B on Mac / Ctrl⇧B on Windows.)

3. Use it on any prototype

  1. Start your local server and open any prototype, e.g. localhost:5500/products/check-it/voicecheck-promo/ver1/ver1.html
  2. Click ✏️ Edit Mode in your bookmarks bar — the editor toolbar appears on the page.
  3. Click an element, tweak it, then hit Finish & Export.
  4. Copy the prompt and paste it into your Claude session in VS Code. Click ✏️ Edit Mode again to turn the editor off.
Why a bookmark and not a button on the page? Anything added to a mock's HTML would ship to GitHub Pages and be public. The bookmarklet lives in your browser, injects the editor only when you click it, and only runs on localhost — so it stays private and touches zero files.
