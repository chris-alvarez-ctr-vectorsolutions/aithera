Vector navigation shell · 5 versions

One shell, real products: every version wraps the actual Vector suite (Convergence · Vector EHS Management · Vector Scheduling + a cross-product Dashboard) in the same shell: location tree picker, scoped search, in-bar mode tabs, 3-level side nav, switcher with the full catalog. V1 and V2 compare the switcher and search placement; V3 to V5 keep V1's shell and vary ONLY how the side nav shows hierarchy. Review toggles in the bottom-left pill flip the customer logo, the location picker and the mode tabs on and off. Earlier explorations live in archive/.

Fixed in every version: the shared shell contract
Nav open/close App switcher Product · Location Scoped search Alerts Help Avatar
The nav open/close control is always the far-left item, directly above the side nav's edge; the app switcher sits next to it and owns that corner in every product. Switching ≠ navigating: other products never appear inside the current product's nav tree, and universal actions never move. Only the middle (mode tabs or nothing) and the side-nav pattern vary per version.
Menus borrow two things from Convergence + EHS (the visual style stays this exploration's own): the disclosure chevron trails the label and flips when open, as in .sn-row / .sb-item, so an expandable row and a plain row at the same level share one icon x and one label x; and the menu vocabulary echoes the real products' IA: Organization / Teams / Departments, Curricula, Qualifications, Activities, My recents / Scheduled reports on the Learn side; Incidents summary, Investigations, Corrective actions, OSHA logs, and the Safety Management long tail (Hazards, JSA, SDS, Tasks, Events, Document library, Observations) on the Comply side.

V1 · Grid launcher · global scoped search

Switcher: waffle launcher + Dashboard Search: top bar · All / product scope Hierarchy: indented accordion + guide lines

The reference shell: waffle launcher (in-panel search, pinned products, All-products expansion, distinct cross-product Dashboard), Convergence-style location tree picker, and a top-bar global search whose scope control reads All or the current product's name. Mode tabs live in the single top bar and live-swap the 3-level side nav. The review pill toggles the customer logo, the location picker and the tabs.

V2 · App rail · side-nav product search

Switcher: app rail · Dashboard on top Search: in the side nav · product-scoped Hierarchy: indented accordion + guide lines

Same shell as V1 with two deliberate differences: the app switcher is an additional left side bar (persistent rail, Dashboard pinned on top, waffle at the bottom for the full catalog), and search lives in the side nav scoped to the current product only ("Search Convergence"), live-filtering the menu. No global search in the top bar. Compare with V1 to weigh global reach against a quieter top bar.

V3 · Hierarchy: flyout panels

Hierarchy: children open to the right Everything else = V1

V1's shell, but a group's children open in a flyout panel to the right of the side nav instead of expanding inline; level 3 nests inside the panel. Opening a group closes its siblings, so one panel shows at a time and the nav itself stays short. Trade-off: children are never visible alongside the whole tree, and the panel briefly covers content.

V4 · Hierarchy: typography only

Hierarchy: weight, size, color Everything else = V1

V1's shell with the guide lines removed: depth reads through type alone. Parents are heavier and darker, each level down lighter, smaller and quieter, with children aligned to their parent's label. The calmest treatment of the three. Trade-off: depth is subtler, so scanning relies on reading rather than tracing a line.

V5 · Hierarchy: tinted open groups

Hierarchy: color of open accordions Everything else = V1

V1's shell where the OPEN accordion headers themselves take color: an open group's header sits on the soft accent tint and a nested open header on the stronger tint, so the open path reads as a colored trail down the nav. No lines, no containers; children simply indent. Trade-off: open-state color shares the accent language with selection, so the active item leans on its bolder face.

Where this lands

V1 and V2 are the live pair: same shell, differing on switcher (waffle launcher vs persistent rail) and search placement (global scoped search in the top bar vs product-scoped search in the side nav). V3 to V5 isolate one question: how should the side nav show hierarchy: flyout panels, typography only, or tinted open groups, on an otherwise identical V1 shell, so the depth language can be chosen independently of the shell decision.
