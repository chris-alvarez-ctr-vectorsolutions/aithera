# Design system brainstorm

Exploration space for cross-product design-system concepts. Not product mockups; nothing in
here is wired into `products.json` or the dashboards.

## Contents

- **`vector-nav/`** · Unified navigation shell exploration: 6 static high-fidelity versions
  of a shared multi-product nav (app switching, 2-3 level side nav, optional Convergence-style
  mode tabs), each varying one structural axis at a time on identical neutral design tokens.
  Start at `vector-nav/index.html` for the gallery; `vector-nav/DESIGN-NOTES.md` has the
  version matrix and recommendation.
